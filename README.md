# DevTrackAI

DevTrackAI is a web application for tracking developer learning progress. It lets you record courses, monitor completion and learning hours, and view summary metrics on a dashboard.

## Features

- Dashboard showing total courses, total learning hours, and average progress.
- Add, edit, list, and delete learning records.
- Track course name, learning platform, progress percentage, and hours spent.
- Validate required fields and progress percentage.

## Technology

- .NET 10
- ASP.NET Core MVC with Razor views
- Entity Framework Core
- SQLite
- Bootstrap

## Prerequisites

- .NET 10 SDK
