🚀 DevTrackAI
Developer Learning & Career Growth Platform

DevTrackAI is a centralized platform designed to help developers track their learning progress, manage job applications, monitor certifications, and prepare for technical interviews.

It provides a unified dashboard with analytics to help developers organize their career journey, measure progress, and achieve their professional goals.

Track technical skills and learning topics.

Track completed and ongoing courses.
💼 Job Tracker

Monitor interview and application progress.

Track professional certifications.

🏗️ Architecture

DevTrackAI follows the ASP.NET Core MVC architecture.

Model: Handles application entities and data structures.
View: Provides the user interface using Razor Views, Bootstrap, and AdminLTE.
Controller: Handles user requests and application logic.
Database: SQLite stores application data.
ORM: Entity Framework Core manages database operations.
⚙️ Getting Started
Prerequisites

Make sure you have installed:

.NET 9 SDK
Visual Studio 2022 or Visual Studio Code
SQLite
Git
Installation

1. Clone the repository

bash
git clone (https://github.com/durgaprsadai-lgtm/DevTrackAI.git)


2. Navigate to the project directory

bash
cd DevTrackAI


3. Restore dependencies

bash
dotnet restore


4. Apply database migrations

bash
dotnet ef database update


5. Run the application

bash
dotnet run


6. Open in browser

Navigate to the local URL displayed in your terminal.

🐳 Docker Support

DevTrackAI includes Docker support for containerized deployment.

Build the Docker image:

bash
docker build -t devtrackai .


Run the container:

bash
docker run -p 8080:8080 devtrackai
